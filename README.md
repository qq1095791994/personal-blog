# 江汉｜空间与实时视觉

个人博客与作品集，展示车机 HMI、智慧城市、空间可视化和 UE 实时场景。近期工作方向为智能空间。

在线地址：[qq1095791994.github.io/personal-blog](https://qq1095791994.github.io/personal-blog/)

## 内容结构

- `index.html`：首页、精选作品、经历和联系信息。
- `site.js`：作品筛选与图集交互；项目说明集中维护在文件开头。
- `styles.css`：桌面与移动端样式。
- `notes/`：实践笔记。
- `assets/world/`：首屏《UE 仙侠》古街的实时 3D 几何、渲染与交互代码。
- `assets/work/`：从个人作品资料中挑选并压缩的图片，以及明确标注的 AI 概念图。
- `assets/*.mp4`：短视频作品。

## 首屏虚拟空间

首屏古街以本人《UE 仙侠》作品中的 `游戏类型/UE仙侠 (4).png`（正街）、`UE仙侠 (5).png`（侧巷）和 `UE仙侠 (6).png`（鸟瞰布局）为视觉与空间参照，在网页中重新制作了程序化 3D 几何。访问者可以拖动或触摸来 360° 环绕查看，切换入口、街心与俯瞰视角，并使用街道漫游、全屏和原作截图对照功能。

作品资料仅包含渲染截图，没有原始 UE 场景或可直接加载的模型。网页里的场景是依据画面手工与程序化构建的**近似重构**，并非原项目模型、自动扫描结果或 AI 精确重建；建筑背面和截图未展示的区域属于创作性补全。图片来源及对应关系见 [图片来源](assets/IMAGE_SOURCES.md)。

## 本地预览

在仓库目录运行 `python -m http.server 8080`，然后打开 `http://localhost:8080/`。修改 `assets/world/` 中的 3D 代码后，运行 `npm ci`（首次）与 `npm run build:world`，更新提交到仓库的浏览器脚本。

## 发布

本站使用 GitHub Pages 的 `main` 分支直发模式，推送到 `main` 后会更新。图片来源与 AI 概念图说明见 [图片来源](assets/IMAGE_SOURCES.md)。
