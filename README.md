# 江汉｜空间与实时视觉

个人博客与作品集，展示车机 HMI、智慧城市、空间可视化和 UE 实时场景。近期工作方向为智能空间。

在线地址：[qq1095791994.github.io/personal-blog](https://qq1095791994.github.io/personal-blog/)

## 内容结构

- `index.html`：首页、精选作品、经历和联系信息。
- `site.js`：作品筛选与图集交互；项目说明集中维护在文件开头。
- `styles.css`：桌面与移动端样式。
- `notes/`：实践笔记。
- `assets/work/`：从个人作品资料中挑选并压缩的图片，以及明确标注的 AI 概念图。
- `assets/*.mp4`：短视频作品。

## 本地预览

在仓库目录运行 `python -m http.server 8080`，然后打开 `http://localhost:8080/`。

## 发布

本站使用 GitHub Pages 的 `main` 分支直发模式，推送到 `main` 后会更新。图片来源与 AI 概念图说明见 [图片来源](assets/IMAGE_SOURCES.md)。
